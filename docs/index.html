scratch2modern

从 microgpt 出发，一步步搭出现代大语言模型

我们从 Karpathy 的 microgpt 开始。它只有两百行纯 Python，是一个完整的 GPT，只是很小，也很慢。之后每一节只往上加一样东西：换成 PyTorch、搬上 GPU、换一个优化器……然后用实验看看它到底带来了什么。

每个结论都有对照实验：一次只改一个变量，学习率各自调好再比，多跑几个随机种子看波动。有的改动让训练快了几十倍，有的让模型明显变好，也有的在我们这个规模上没有用，那就去找它在什么条件下才有用。

每一节对应仓库里一个能直接运行的脚本，和上一节 diff 一下就是这一节的全部改动。建议边读边跑，自己改改参数。
