怎么做

大模型的训练配方里有几十个部件，各有论文、各有默认值。我们关心的是：拿掉它会怎样，加上它又换来了什么。

一次只改一处

每一节是一个能单独运行的脚本。和上一节 diff，就是这一节的全部改动。

  def linear(x, w):
-     return [sum(wi * xi for ...) for wo in w]
+     return w @ x

每个结论都有实验

只改一个变量，训练量按 token 对齐。优化器、调度各自扫学习率，取最好的再比；多个随机种子看波动，差距小于波动的算打平。

小模型和大模型对照

玩具规模上看到的，不一定在大模型上成立。每一节都对照真实大模型的做法，说清楚哪些结论能推广，哪些不能，为什么。
