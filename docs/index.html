scratch2modern

从 microgpt 到现代大语言模型

Andrej Karpathy 的 microgpt 用两百行纯 Python 训练了一个 GPT。读数据、搭模型、求梯度、更新参数、生成文本，全部手写，不依赖任何库。它是一个完整的语言模型，只是很小，也很慢。

今天的大模型用的是同一套算法，差别在于围绕它发展出来的一切：怎样训练得更快、更稳，模型结构怎样改进，训练完以后怎样让它听懂指令，以及怎样把这一切铺到成千上万张 GPU 上。这些东西各有论文、各有默认值，散落在各处，很难看出哪些是必需的，各自又在解决什么问题。

这里的做法是从 microgpt 出发，每次只加一样东西。每一节先讲它是什么、为什么需要它，再把它加进代码，用实验看它到底带来了什么。有的改动让训练快了几十倍，有的让模型明显变好，也有的在我们的规模上不起作用，那就讲清楚它要在什么条件下才起作用。

每一节对应仓库里一个可以单独运行的脚本，和上一节的 diff 就是这一节的全部改动。所有实验都在一张 GPU 上完成，可以自己复现。
